# junwoop0.github.io

Personal homepage of Junwoo Park — [junwoop0.github.io](https://junwoop0.github.io/)

Plain static HTML/CSS, no build step (`.nojekyll` disables Jekyll on GitHub Pages).

- `index.html` — all content (about, news, education, research, publications, projects, awards)
- `assets/css/style.css` — styling; light/dark follows the visitor's OS setting
- `assets/Junwoo_Park_CV.pdf` — CV linked from the page

To preview locally:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
